## Статус

Навчальний комплект: 23 номери апаратів, 43 мережі та 68 сегментів.
Габарити шафи й контури апаратів прийняті для навчального компонування.
Фізичні клеми, STO, фактичні Footprint, теплові відступи та номінали
не підтверджені; матеріали не є завершеним документом для виробничого монтажу.

DWG потрібно отримати через SAVEAS у AutoCAD; реальні скріншоти етапів
додати самостійно. stage01–03 — ілюстрації креслень, а не скріншоти AutoCAD.
Жовтий колір у DXF — лише графічний; реальний PE має зелено-жовту ізоляцію.
