# Лабораторна №3 — варіант 2

Проєкт AQLogic для обчислення площі кола: **S = π × R²**.

[Завантажити проєкт Lab3_Variant2_PR200.aql](./Lab3_Variant2_PR200.aql?raw=true)

## Як відкрити

1. В AQLogic 2.5.362 виберіть **Файл → Відкрити** та відкрийте файл `.aql`.
2. На схемі є два блоки `fMUL`, дійсні змінні `R`, `R2`, `S` і константа `π = 3,1415927`.
3. У менеджері екранів відкрийте **Circle area**: верхній рядок `R=` дозволяє вводити радіус від 0 до 10; нижній рядок `S=` відображає площу з трьома знаками після крапки.
4. Виконайте компіляцію та запустіть симуляцію. Початкове `R = 2,5`; очікуваний результат — `S = 19,635`.

Модель приладу: **ПР200-24.2(4).X.X (PR200DCA)**. Перед записом у реальне реле перевірте відповідність моделі та налаштуйте порт.

## Контрольні значення

| R | S |
|---:|---:|
| 0 | 0,000 |
| 0,5 | 0,785 |
| 1 | 3,142 |
| 2 | 12,566 |
| 2,5 | 19,635 |
| 5 | 78,540 |
| 10 | 314,159 |

Формат схеми й екрана перевірено оригінальними бібліотеками AQLogic; перевірено всі з’єднання та сім обчислень із 32-бітною рухомою комою. Відкриття у графічному AQLogic під Windows, компіляція й робота на реальному ПР200 ще не перевірені.
